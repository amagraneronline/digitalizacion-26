¿Qué hace un
sistema operativo?

El sistema operativo (SO) coordina los recursos del ordenador para que puedas usar tus aplicaciones.

A / Conceptos

Cinco funciones principales

  1. 01

    Procesos y CPU

    Al ejecutar un programa se crean uno o más procesos. El SO reparte entre ellos el tiempo del procesador (CPU).

  2. 02

    Memoria RAM

    El SO asigna a cada programa espacio en la memoria temporal (RAM) y lo libera cuando el programa termina.

  3. 03

    Archivos y carpetas

    El SO organiza los archivos en carpetas dentro del almacenamiento. Permite guardarlos, localizarlos, moverlos o borrarlos.

  4. 04

    Dispositivos y periféricos

    El SO usa programas llamados controladores para comunicarse con dispositivos como el teclado o la impresora.

  5. 05

    Usuarios y permisos

    El SO identifica al usuario y comprueba qué acciones tiene permitidas, como leer, modificar o borrar un archivo.

B / Caso de aula

Un informe para clase

Preparas un informe en Word en el ordenador del aula.

Lo que hacesLo que hace el sistema operativo
  1. 01 / Procesos y CPU

    Consultas una web

    Escribes en Word mientras el navegador carga una página. El SO reparte tiempo de CPU entre los dos programas.

  2. 02 / Memoria RAM

    Insertas una foto

    Word pide más memoria para editar la foto. El SO le asigna RAM y la recupera cuando cierras el programa.

  3. 03 / Archivos y carpetas

    Pulsas «Guardar»

    Word pide al SO que escriba Informe.docx en el disco. Aunque apagues el equipo, el archivo seguirá en su carpeta.

  4. 04 / Dispositivos

    Imprimes una copia

    El SO pone el informe en la cola de impresión y lo envía a la impresora del aula mediante su controlador.

  5. 05 / Usuarios y permisos

    Tu compañero lo abre

    Su cuenta tiene permiso de lectura. El SO le deja abrir el informe e impide que guarde cambios en el original.
