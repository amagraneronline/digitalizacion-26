Infografía de clasificación

¿Cómo se clasifican los sistemas operativos?

Podemos clasificarlos de varias maneras: según su licencia, el dispositivo para el que están pensados y la forma en que nos comunicamos con ellos.

A / Según su licencia

Libres o privativos

Software libre

Su licencia permite usar el sistema, estudiar su código fuente, modificarlo y compartirlo respetando las condiciones de esa licencia.

Debian Ubuntu Fedora
¿Qué implica usarlo?

Podemos conocer cómo funciona, adaptarlo y compartir mejoras. Libre no siempre significa gratis.

Software privativo

Su código fuente no está disponible libremente y la licencia limita lo que el usuario puede hacer con el sistema.

Windows macOS iOS
¿Qué implica usarlo?

Podemos utilizarlo según su licencia, pero no modificar ni distribuir libremente su código. El desarrollo depende sobre todo de la empresa responsable.

Idea clave: que un sistema operativo sea gratuito no significa que sea libre. Lo importante son los permisos que concede su licencia.

B / Según el dispositivo

Escritorio o móvil

Cada sistema operativo se diseña pensando en el tipo de aparato en el que va a funcionar.

Escritorio

Está pensado para ordenadores de sobremesa y portátiles.

  • Usa teclado, ratón, impresora y otros periféricos.
  • Permite trabajar con varios programas y archivos.
  • Suele tener ventanas, menús y carpetas visibles.

Ejemplos: Windows, macOS, Ubuntu.

Móvil

Está pensado para teléfonos inteligentes y otros dispositivos táctiles.

  • Se adapta a la pantalla táctil y a la batería.
  • Gestiona sensores como GPS, cámara o acelerómetro.
  • Está preparado para llamadas, datos móviles y apps táctiles.

Ejemplos: Android, iOS.

Idea final Un mismo sistema operativo puede describirse con varios criterios a la vez.

C / Según la interfaz

GUI o CLI

La interfaz es la forma en la que el usuario se comunica con el sistema operativo. No son sistemas diferentes: son dos maneras de usarlo.

02

Graphical User Interface

GUI · Interfaz gráfica

Permite usar el sistema mediante ventanas, iconos, menús y botones.

  • Hace más visual y sencilla la interacción.
  • Sirve para abrir programas, mover archivos y cambiar ajustes.
  • Se usa con ratón, teclado o pantalla táctil.

Command-Line Interface

CLI · Línea de comandos

Permite usar el sistema escribiendo comandos de texto en una terminal o consola.

  • Es muy útil para tareas rápidas y repetitivas.
  • Sirve para consultar información, gestionar archivos y automatizar procesos.
  • Requiere conocer los comandos adecuados.

D / La misma tarea, dos caminos

Crear una carpeta llamada «Tareas»

Con GUI

Usas el explorador de archivos y seleccionas la opción de crear carpeta.

Acción: clic derecho → Nuevo → Carpeta.

Con CLI

Abres una terminal y escribes una instrucción para crearla.

Comando: mkdir Tareas

E / Esquema final

Tres criterios de clasificación

1. Según la licencia

Libres · podemos estudiar, modificar y compartir el código. Privativos · su uso depende de una licencia más cerrada.

2. Según el dispositivo

De escritorio · para ordenadores. Móviles · para teléfonos y dispositivos táctiles.

3. Según la interfaz

GUI · visual, con ventanas e iconos. CLI · textual, mediante comandos.

Ejemplo completo

Ubuntu puede describirse como un sistema operativo de escritorio, de software libre y que permite usar GUI y CLI.

F / Comprueba si lo entendiste
