A / Definición

¿Qué es un
sistema operativo?

Un sistema operativo (SO) es el software básico de un dispositivo. Hace de intermediario entre las aplicaciones y el hardware, la parte física del equipo.

B / Utilidad

¿Para qué sirve?

Te permite utilizar un ordenador, un móvil o una tableta a través de sus aplicaciones. Así puedes redactar un trabajo o hablar por videollamada.

C / Esquema

Del usuario al hardware

Las flechas muestran el camino que sigue una petición.

  1. Usuario

    Decide qué quiere hacer y lo indica en la aplicación.

    da una orden

  2. Aplicación

    Recoge la orden y pide al SO lo que necesita para llevarla a cabo.

    pide un servicio

  3. Sistema operativo

    Recibe la petición y se comunica con el dispositivo adecuado.

    envía la orden

  4. Hardware

    Es la parte física del equipo que lleva a cabo la acción solicitada.

D / Caso de aula

Escuchas un diálogo en clase

Tienes una grabación abierta en el ordenador y quieres oír una frase en inglés.

Quién intervieneQué ocurre
  1. 01 / Usuario

    Tú

    Pulsas el botón «Reproducir» para escuchar cómo se pronuncia la frase.

  2. 02 / Aplicación

    El reproductor

    Prepara los datos de audio de la grabación y pide a Windows que los reproduzca.

  3. 03 / Sistema operativo

    Windows

    Envía el audio a la salida elegida mediante el controlador de sonido, el programa que le permite comunicarse con ese dispositivo.

  4. 04 / Hardware

    Los altavoces

    Convierten la señal de audio en vibraciones del aire. Así llega la frase a tus oídos.

¿Y si eliges los auriculares como salida?

Windows envía la misma grabación a los auriculares. Sigues usando el mismo reproductor.
