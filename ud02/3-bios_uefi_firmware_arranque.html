El software que despierta el ordenador

BIOS / UEFI
y firmware

Cuando pulsas el botón de encendido, Windows o Linux todavía no están funcionando. Otro programa prepara el ordenador para arrancarlos.

A / Ideas esenciales

Tres conceptos que debes distinguir

  1. 01

    Firmware

    Es software integrado en un dispositivo. En el ordenador, el firmware de la placa base se guarda en una memoria no volátil y empieza a ejecutarse al encenderlo.

    Qué esSoftware de base que inicia el equipo
  2. 02

    BIOS tradicional

    Es una forma antigua de firmware de los PC. Inicializa componentes, realiza comprobaciones y busca cómo comenzar a cargar el sistema operativo.

    GeneraciónArranque clásico o «Legacy»
  3. 03

    UEFI

    Es el estándar moderno que sustituye a la BIOS tradicional. El firmware basado en UEFI también prepara el arranque y puede incorporar funciones como el Arranque seguro.

    GeneraciónArranque moderno de la mayoría de los PC

B / Cómo se relacionan

El relevo hasta llegar al SO

Secuencia simplificada de arranque

Cada uno realiza una tarea distinta

EnciendesPulsas el botón
FirmwareBIOS / UEFI prepara
CargadorInicia la carga del SO
SO listoYa puedes usarlo

El firmware actúa primero; el sistema operativo toma después el control principal del equipo.

Idea clave: «Firmware» es la categoría general. BIOS y UEFI son tecnologías de firmware para el arranque del PC. No son Windows ni Linux, y no hacen el mismo trabajo que el sistema operativo.

C / Paso a paso

¿Qué ocurre al arrancar el ordenador?

Del botón de encendido a la pantalla de inicio de sesión, en seis pasos.

06
Firmware Transición Sistema operativo
  1. 01

    Pulsas el botón de encendido

    El ordenador recibe energía y el procesador comienza a ejecutar el firmware de la placa base. El SO aún no está iniciado.

    Firmware
  2. 02

    Comprueba el hardware (POST)

    El firmware inicializa y comprueba componentes esenciales, como la memoria RAM. Si detecta un fallo importante, puede mostrar un aviso.

    Firmware
  3. 03

    Localiza una opción de arranque

    Según el orden configurado, busca desde dónde iniciar el equipo: por ejemplo, el SSD donde está instalado Windows o Linux.

    Firmware
  4. 04

    Se ejecuta el cargador de arranque

    El firmware pone en marcha el programa que se encargará de encontrar y empezar a cargar el sistema operativo.

    Transición
  5. 05

    Se carga el sistema operativo

    Se carga en la RAM su núcleo (kernel) y se inician controladores y servicios necesarios para que funcione.

    Sistema operativo
  6. 06

    Aparece la pantalla de inicio

    El SO termina de prepararse, muestra la pantalla para iniciar sesión o el escritorio y ya puedes abrir tus aplicaciones.

    Sistema operativo

D / Ejemplo real

¿Por qué puedes ver un error sin que Windows haya arrancado?

Si el ordenador no encuentra una opción válida de arranque, la BIOS o UEFI puede mostrar un mensaje de error. ¡Eso demuestra que el firmware funciona antes que el sistema operativo!
